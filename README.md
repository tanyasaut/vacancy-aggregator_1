# Агрегатор вакансий

Автоматизированный агрегатор вакансий — консольное приложение для автоматического сбора, обработки и представления информации о вакансиях с различных сайтов по трудоустройству.

## Что умеет приложение

### Сбор вакансий
- Автоматически загружает вакансии с сайтов по трудоустройству (Habr Career, Trudvsem)
- Можно настроить, с каких именно сайтов парсить
- Извлекает нужную информацию
- Исключает дубликаты 

### Обработка и хранение данных
- Очищает данные от лишней информации
- Группирует вакансии по категориям 
- Сохраняет всё в базу данных для быстрого доступа

### Фильтрация и поиск
- Фильтрует вакансии по разным параметрам
- Ищет по ключевым словам в заголовке или полном тексте вакансии
- Настраиваемые уведомления 

### Пользовательский интерфейс
- Консольное меню с понятными командами
- Показывает список вакансий с заголовком, компанией, зарплатой и кратким описанием
- Можно открыть полную вакансию на оригинальном сайте
- Сортировка по дате, зарплате, компании
- Экспорт данных в CSV, JSON, HTML

### Обновление данных
- Автоматически обновляет список вакансий
- Можно запустить обновление вручную

### Аналитика и статистика
- Показывает количество вакансий по разным параметрам
- Считает среднюю зарплату по разным параметрам
- Распределяет вакансии по категориям зарплат 
- Сортирует вакансии по зарплате для удобного анализа
